## 3. 验证方式

### 3.1 后端验证

```bash
cd backend
mvn test
# 预期：所有单元测试通过，覆盖率 ≥ 80%
```

### 3.2 前端验证

```bash
cd front
npx vitest run
# 预期：所有组件测试通过（11 tests passed）

npx vite build
# 预期：构建成功，无TypeScript错误
```

### 3.3 集成验证

1. 启动后端：`cd backend && mvn spring-boot:run`
2. 启动前端：`cd front && npm run dev`
3. 浏览器访问 `http://localhost:5173/room-status`
4. 验证项：
   - 房间网格正确渲染（显示所有房间卡片）
   - 楼层筛选正常工作（切换标签过滤房间）
   - 状态修改后实时更新（点击菜单修改状态）
   - 详情抽屉正确展示（点击卡片弹出详情）
   - SSE实时推送（多窗口同步）

## 5. 风险与应对

| 风险 | 影响 | 应对措施 |
|------|------|----------|
| MySQL连接配置 | 后端无法启动 | 提供H2内存数据库作为开发替代 |
| SSE连接不稳定 | 看板数据不同步 | 实现自动重连+定时轮询兜底 |
| 大量房间性能 | 页面卡顿 | 客户端过滤+虚拟滚动（>200间时） |
| 并发状态修改 | 数据不一致 | 后端乐观锁+版本号校验 |
